1. BOTNI OCHING
Telegram'da o‘zingiz yaratgan botga /start yuboring.
2. BOT TOKENINI SERVERGA ULANG
Bot tokenini brauzer HTML fayliga joylamang. Token maxfiy bo‘lishi kerak.
3. ID AVTOMATIK OLINADI
Bot update olganda message.from.id foydalanuvchining Telegram ID'sini beradi.
POST /api/telegram/id
Muhim: Telegram Bot API oddiy username yozib, istalgan foydalanuvchining ID'sini ruxsatsiz topish uchun universal lookup funksiyasini bermaydi. Shuning uchun bu sahifa soxta ID chiqarmaydi. Foydalanuvchi bot bilan muloqot qilganda ID rasmiy update orqali olinadi.
