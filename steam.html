STEAM • OCHIQ PROFIL QIDIRUV

Steam profilini qidirish

SteamID64, foydalanuvchi nomi (vanity) yoki profil havolasini kiriting — Steam'ning rasmiy ochiq API orqali shaxsiy sahifa ma'lumotini olib ko'rsatamiz.

Maslahat: SteamID64 (17 xonali raqam), vanity nom yoki to'liq profil havolasi ishlaydi. Faqat ochiq (public) profillarda barcha ma'lumot ko'rinadi.
Eslatma (sayt egasi uchun): Steam qidiruvi ishlashi uchun Google Apps Script loyihasida Script Properties bo'limiga STEAM_API_KEY qo'shilishi kerak. Kalitni steamcommunity.com/dev/apikey dan bepul olish mumkin. Kalit hech qachon sayt kodiga yozilmaydi — faqat server tomonidagi Script Properties'da saqlanadi.
Maxfiylik: bu yerda faqat foydalanuvchi o'zi ochiq (public) qilib qo'ygan Steam profil ma'lumotlari ko'rsatiladi — bu xuddi Steam saytining o'zida ko'rinadigan ma'lumot. Yopiq (private) profillarda faqat ism va rasm ko'rinishi mumkin.
